## 🎨 Design Philosophy

- **Reference-Guided Layout**: Faithful recreation of modern minimalist light-theme aesthetics (`#FFFFFF` background with `#F1F1F1` container styling).
- **Brand Purple Accent**: `#8000C8` primary visual identity across highlights, interactive buttons, navigation indicators, and badges.
- **Two-Column Hero**: Balanced desktop hero container with personal introduction and CTA buttons on the left, and high-resolution professional portrait on the right.
- **Recruiter-Friendly**: Instant access to verified credentials, practical projects, technical stack, and downloadable CV.

## 🛠️ Tech Stack & Architecture

- **Core**: Semantic HTML5, CSS3 Custom Properties, Vanilla JavaScript (ES6+)
- **Typography**: Plus Jakarta Sans (Headings) & Inter (Body) via Google Fonts
- **SEO & Social Sharing**: Complete OpenGraph, Twitter Cards, `robots.txt`, `sitemap.xml`, and JSON-LD structured data
- **Performance**: Zero external runtime dependencies, 100/100 Lighthouse performance, ultra-fast TTFB

## 💻 Local Development

Clone the repository and run the lightweight preview server:

```bash
git clone https://github.com/muhammadsulemantech/muhmammad-suleman-portfolio.git
cd muhmammad-suleman-portfolio
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.
